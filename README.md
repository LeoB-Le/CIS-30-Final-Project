# CIS-30 Final Project Monthly Personal Finance Tracker

A simple Python program that helps users track monthly income, expenses, budget, and savings goals using a Tkinter graphical interface.

## Features

- Add income and expenses
- Calculate total income and expenses
- Display remaining balance
- Check budget and savings goals
- Handle invalid input
- Save a financial summary to a text file

## Files

- `main.py` — Tkinter interface and program controls
- `financeClasses.py` — Classes for transactions and budgeting
- `financeTools.py` — Summary and file-saving functions
- `financeSummary.txt` — Saved financial summary
